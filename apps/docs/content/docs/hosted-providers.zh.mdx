在 Web 的 Nodes 页面添加节点，并在目标主机执行经过校验的命令。sudo 模式使用 oac-node 系统账户；无 sudo 模式使用用户服务。节点程序不支持通过 --update 升级版本；保留旧节点状态和 Runtime 数据，另行添加新节点。当前 Runtime generation 操作不属于节点程序版本升级。
