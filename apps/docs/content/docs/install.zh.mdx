安装器默认在 ~/.oac/core 安装 Core、Web 和专用 PostgreSQL，初始没有执行节点。先确定公网 HTTPS 地址，按当前版本的校验步骤下载并安装，再用 Core key 登录 Web。 只支持全新安装与同一版本修复；不支持旧版本原地升级或历史转换。保留旧安装和数据，在新的空目录安装当前版本。
