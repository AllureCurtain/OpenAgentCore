使用 oac status 查看安装状态，oac start 和 oac stop 管理服务，oac apply 应用 config.json。备份必须同时保留数据库、配置和密钥。只支持全新安装和同一版本修复，不支持原地升级、降级或历史转换；保留旧安装和数据，在新的空目录重新安装。安装、修复和修改状态的 oac 命令共用 .oac.lock；遇到占用应等待当前命令结束，不要删除或替换锁文件。
