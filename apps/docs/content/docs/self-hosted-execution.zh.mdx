self_hosted 执行器由用户拥有，通过 Web 为对应 Environment 签发凭据。Linux、macOS 和 Windows 使用同一 daemon 协议；daemon 以启动账户权限运行，隔离由外层环境负责。凭据通过私有文件提供，不放入命令行。
